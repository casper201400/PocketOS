# PocketOS

# Your pocket. Your system.

PocketOS is a custom operating system project built around the ESP32-2432S028 (Cheap Yellow Display / CYD). The goal is to turn a small touchscreen development board into a compact, phone-like device with its own interface, applications, settings, and features.

About the Project

PocketOS is designed to bring a smartphone-style experience to a small embedded device without relying on an existing mobile operating system.

The project focuses on creating a custom interface, experimenting with embedded software, and exploring what can be achieved with an ESP32 touchscreen.

Hardware

Main board: ESP32-2432S028 CYD

Display: 2.8-inch ILI9341 touchscreen

Resolution: 240 × 320 pixels

Touch controller: XPT2046

Microcontroller: ESP32

Development environment: Arduino IDE

Features

PocketOS is designed with a collection of built-in applications:

Phone: Phone-style interface.

Messages: Messaging interface concept.

Camera: Camera functionality.

Photos: Photo viewing.

Settings: Customizable device settings.

Clock: Time display.

Calculator: Basic calculations.

Files: File management.

Weather: Weather interface.

Music: Music interface.

Terminal: Command-line-style interface.

Customization

PocketOS includes customization options such as:

Multiple wallpapers.

Different accent colors.

Persistent settings.

Custom application icons.

A PIN-based lock screen.

Development

PocketOS is developed using Arduino and C++ with libraries for display rendering, touchscreen input, and device storage.

The project uses:

LovyanGFX for graphics and display handling.

ESP32 Preferences for persistent settings.

XPT2046 touchscreen input.

The goal is to keep the software lightweight and suitable for the ESP32's hardware limitations.

Project Goals

Future development aims to include:

More applications and modules.

Improved animations and transitions.

Better file management.

Additional hardware integrations.

More customization options.

A custom PCB with charging and update capabilities.

Further improvements to the overall user experience.

Why PocketOS?

PocketOS started as an experiment to see whether a small ESP32 touchscreen could become something more than a simple development board.

Instead of using a pre-existing interface, the project builds its own software environment from the ground up.

The long-term vision is to create a modular, customizable pocket-sized device.
